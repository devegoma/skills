# skills

このリポジトリは、個人的に使用する各種スキルの定義を管理するためのものです。
作成の都度、ここに追加していきます

## 含まれるスキル

- [plan-checklist](skills/plan-checklist/): 作業計画書とチェックリストを作成・更新します。作成・更新後は [yomiyasu](https://github.com/nanaism/yomiyasu) スキルで日本語を推敲します。
- [architecture-flow](skills/architecture-flow/): リポジトリのアーキテクチャと代表的な動作フローを、コード上の根拠付きで解説します。
- [explain-flow](skills/explain-flow/): 選択中の関数や処理のコードフロー、分岐、状態変化を根拠付きで解説します。
- [dependency-audit-fix](skills/dependency-audit-fix/): パッケージマネージャーを検出し、依存関係の脆弱性監査と互換性を保つ自動修正を繰り返して、結果をテーブルで報告します。
- [tdd-from-plan](skills/tdd-from-plan/): 作業計画書の未完了項目を選び、TDDで実装して検証結果と進捗を計画書へ記録します。コード変更時は `tdd` スキル（[mattpocock/skills](https://github.com/mattpocock/skills/tree/main/skills/engineering/tdd)）と [ponytail](https://github.com/DietrichGebert/ponytail/tree/main/skills/ponytail) スキルを事前に読み込みます。
