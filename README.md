# skills

このリポジトリは、個人的に使用する各種スキルの定義を管理するためのものです。
作成の都度、ここに追加していきます

## 含まれるスキル
- [plan-checklist](skills/plan-checklist/): 作業計画書とチェックリストを作成・更新します。
- [architecture-flow](skills/architecture-flow/): リポジトリのアーキテクチャと代表的な動作フローを、コード上の根拠付きで解説します。
- [explain-flow](skills/explain-flow/): 選択中の関数や処理のコードフロー、分岐、状態変化を根拠付きで解説します。
- [tdd-from-plan](skills/tdd-from-plan/): 作業計画書の未完了項目を選び、TDDで実装して検証結果と進捗を計画書へ記録します。コード変更時は Matt Pocock 氏の `tdd` スキル（[mattpocock/skills](https://github.com/mattpocock/skills)）を事前に読み込みます。
